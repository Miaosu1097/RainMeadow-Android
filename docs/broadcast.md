# 平台标识广播

移植版在 Android 上向支持接收的房间成员发送平台标识。该标识通过 Rain Meadow 的自定义包通道传输，沿用现有的大厅状态与玩家 ID 格式。Android 主包包含发送功能，桌面环境不会启动发送。

## 发送时机

客户端在加入房间并完成连接后的短暂等待结束后开始广播，此后定期向已同步订阅信息的房间成员发送。接收端稍晚完成状态同步时，可以在后续发送轮次收到标识。

## 反制模组对接

房主端可使用 [PC 反制模组](../companion/KickAndroid/README.md) 接收标识。具体的安装方法、配置和处理方式见该模组文档。

标识由客户端上报，接收结果适合作为房主策略的参考。
